# ISO 15223-1:2021 – symbols commonly used on Pillar IVD labels

Correct citation format: `ISO 15223-1:2021` (space after ISO, colon before the year).
Compare these clause numbers with the controlled copy of the standard before using them in a
formal record.

| Name as listed in spec | ISO 15223-1:2021 title | Clause | Graphic (what to look for) | Accompanying data |
|---|---|---|---|---|
| Manufacturer symbol | Manufacturer | 5.1.1 | **Filled** (solid black) factory | Manufacturer name and address next to it |
| Date of manufacture | Date of manufacture | 5.1.3 | **Outlined** (hollow) factory | Date, YYYY-MM-DD |
| Expiration Date symbol | Use-by date | 5.1.4 | Hourglass | Expiry date, YYYY-MM-DD |
| LOT (lot number) | Batch code | 5.1.5 | `LOT` in a box | Lot number |
| REF (catalogue number) | Catalogue number | 5.1.6 | `REF` in a box | Catalogue/part number (e.g. PB-0108) |
| Serial number | Serial number | 5.1.7 | `SN` in a box | Serial number |
| Temperature Limit symbol | Temperature limit | 5.3.7 | Thermometer with upper and lower bars | Both limits with units (e.g. -25°C, -15°C) |
| Upper limit of temperature | Upper limit of temperature | 5.3.6 | Thermometer, upper bar only | One limit |
| Lower limit of temperature | Lower limit of temperature | 5.3.5 | Thermometer, lower bar only | One limit |
| Consult instructions for use | Consult instructions for use | 5.4.3 | Book with "i" | – |
| Caution symbol | Caution | 5.4.4 | Triangle with `!` | – |
| IVD | In vitro diagnostic medical device | 5.5.1 | `IVD` in a box | – (not for IUO/RUO products) |
| Control | Control | 5.5.2 | `CONTROL` in a box | – |
| Negative control | Negative control | 5.5.3 | `CONTROL –` in a box | – |
| Positive Control symbol | Positive control | 5.5.4 | `CONTROL +` in a box | – |
| Contains sufficient for <n> tests | Contains sufficient for <n> tests | 5.5.5 | Σ (sigma) in a triangle-like outline | n, the number of tests (e.g. 24) |
| UDI | Unique device identifier | 5.7.10 | `UDI` in a box | UDI carrier (2D barcode + HRI) |

## Symbols that are NOT in ISO 15223-1

| Symbol | Note |
|---|---|
| IUO (Investigational Use Only) | Company/regulatory convention. List without an ISO citation; show it together with the text "Investigational Use Only". |
| RUO (Research Use Only) | Same as IUO. |

## GS1 / UDI human-readable interpretation (HRI)

| AI | Meaning | Format |
|---|---|---|
| (01) | GTIN | 14 digits |
| (10) | Batch/lot | alphanumeric, up to 20 characters |
| (11) | Production (manufacture) date | YYMMDD, no separators |
| (17) | Expiration date | YYMMDD, no separators |
| (21) | Serial number | alphanumeric |

The dates in the HRI must match the human-readable dates printed elsewhere on the label
(e.g. `(17)231025` ⇔ use-by `2023-10-25`; `(11)231023` ⇔ manufactured `2023-10-23`).
